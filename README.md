# Gopeed Extension: MediaFire Downloader

Download files from MediaFire directly in Gopeed. This extension automatically resolves MediaFire links to direct download URLs, making downloads faster and more reliable.

## Features

- Automatic extraction of direct download links from MediaFire URLs
- Lightweight and fast
- No additional dependencies required
- Supports all MediaFire file links

## Installation
1.Copy URL this repo.
2.Open Gopeed -> extensions 
3.Past URL.
4.Done.

## Usage

1. Copy a MediaFire file link (e.g., `https://www.mediafire.com/file/...`).
2. Paste it into Gopeed to create a new download task.
3. The extension will automatically resolve the direct download link and start the download.

## Development

This extension is built using JavaScript and follows the Gopeed extension API.

- `manifest.json`: Extension configuration
- `index.js`: Main logic for link resolution
